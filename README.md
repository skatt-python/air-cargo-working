## 🎯 Описание проекта

AirCargo Platform - это веб-платформа для организации грузовых авиаперевозок. Система позволяет:

- **Грузовладельцам** создавать заявки на перевозку грузов
- **Агентам перевозчиков** предлагать свои услуги и цены
- **Автоматизировать** процесс выбора оптимального перевозчика
- **Управлять** всем процессом перевозки в одном месте

## ✨ Функциональность

### ✅ Реализовано:
1. **Базовый каркас Django проекта**
   - Настройки проекта (config/settings.py)
   - Маршрутизация (config/urls.py)
   - Виртуальное окружение

2. **Приложение Shipments (Заявки)**
   - Модель Shipment с основными полями
   - Список всех заявок
   - Базовые шаблоны

3. **Приложение Bids (Предложения)**
   - Модель Bid для предложений перевозчиков
   - Список предложений
   - Связь с заявками

4. **Вспомогательные приложения**
   - Accounts (аутентификация)
   - Dashboard (панель управления)

5. **Административная панель**
   - Управление пользователями
   - Управление заявками и предложениями
   - Доступ по: `/admin` (admin/admin123)

### 🚧 В процессе разработки:
1. **Полная система предложений**
   - Создание предложений агентами
   - Принятие/отклонение предложений
   - Уведомления сторон

2. **Расширенная аутентификация**
   - Регистрация пользователей
   - Разделение ролей (грузовладелец/агент)
   - Восстановление пароля

3. **Dashboard с аналитикой**
   - Статистика по заявкам
   - Графики и отчеты
   - Уведомления

## 🛠 Технологии

- **Backend:** Django 4.1.13 (Python)
- **Frontend:** HTML, CSS, Bootstrap 5
- **База данных:** SQLite (разработка), PostgreSQL (продакшн)
- **Аутентификация:** Django Auth
- **Шаблонизатор:** Django Templates
- **Версионность:** Git, GitHub
